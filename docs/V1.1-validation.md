# V1.1 验证记录

日期：2026-10-17。范围：玩法介绍、用户提供的 60 秒循环音乐、踢飞动物时的合成猫叫、初始 3 / 上限 5 HP。

## 实现与素材

- 选人页 / 暂停菜单均可打开原生介绍弹窗，支持滚动、焦点约束、按钮关闭与 Escape。Safari 触摸不自动聚焦按钮，因此显式记录并恢复入口焦点，避免关闭介绍时误恢复对局。
- 背景音乐仅在用户开始游戏后播放；暂停、后台、结果页、返回选人停播，继续时续播，重开归零。音乐与合成音效共享一个持久化声音开关，存储和媒体加载失败不会阻止游戏。
- 单个 HTML Audio 播放器播放 AAC；Web Audio 合成一次约 0.64 秒的「喵」。仅成功 Kick 计数增加时触发，不在持续定格 / 每帧更新中重播。
- `Music/` 原始 MP3 约 2.48 MB、实际长约 62 秒；网页副本准确取前 60 秒，AAC 96 kbps、720,665 字节。原文件不进入部署目录，转换脚本不参与 CI 构建。
- 初始 3 HP / 上限 5 HP 独立配置；满血吃南瓜显示「生命已满」，不会误报 +1。HUD 五心中开局亮三颗。

## 自动化

- 69 项单元测试通过，覆盖 3 → 4 → 5、满血不溢出、新局归 3、5 次有效伤害后结束，以及原有战斗 / 归因 / 长局规则。
- 浏览器完整回归首轮 45 通过、1 失败、1 按设计跳过。失败用例是自动化在恢复输入前 / 动物离开前未能有效 Kick；改为暂停准备并在恢复帧后通过正常按钮处理器触发，桌面 Chromium / 手机 Chromium / WebKit 三项复测均通过。共验证 46 个有效用例；最终云端完整回归见 [Check CatBall](https://github.com/qqqqqhanyu/CatBall/actions/workflows/ci.yml)。
- 新浏览器用例覆盖：568×320 玩法介绍与暂停；BGM 实际播放、在尾部跳转后跨越 60 秒循环、暂停续播 / 重开 / 静音记忆；鸭子和野猪各一次猫叫、空踢和静音不播放；真实拾取与五心 HUD；音频失败和存储禁用时仍能完整结束一局。
- TypeScript 与 GitHub 子路径构建通过；Cloudflare 根路径构建通过。根路径生产包约 7.34 MB，WebKit 实际进入游戏并播放音乐，无脚本错误或 HTTP 失败，生产页面没有开发调试接口。
