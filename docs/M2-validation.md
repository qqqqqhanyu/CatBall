# M2 核心弹幕验证 · 2026-10-16

实现范围：四名移动投球者、普通／三射／大球、统一难度调度、3 HP、受伤无敌、Game Over、结算与本地最佳纪录。维持已确认的操场、角色、原图头像和四帧腿部动画；Kick／Roll、动物、道具及表情气泡分别等待 M3／M4。

## 行为与实现

- `AttackDirector` 管理唯一的全场攻击时钟，随机选择投球者，0.5 秒蓄力后重新读取玩家位置。发射后固定速度与方向。
- 投球者使用矩形周长坐标连续移动，随机改变顺逆方向，彼此保留间距。顶部轨道距蓝场 40 世界像素，保证贴边玩家不会与刚生成的大球重叠。
- 24 球上限按整个事件检查；三射需要 3 个空位。等待期间不删除现有球、不堆积补偿连射。相邻大球事件选择不同发射者。
- 难度表、球速倍率、大小、无敌时间等集中在 `gameConfig.ts`。180 秒后的速度连续增加，最高 1.9 倍。
- 相对运动的连续圆碰撞检测处理快速交叉与擦边；无敌恰好在一帧中结束时，不追溯计算此前的免疫接触；每帧只处理最早的一次有效伤害。产生伤害的那颗球消失，其余球在 1.2 秒受伤无敌期间继续飞行，无重复命中事件。
- 暂停和结束冻结所有有效游戏时间、运动、蓄力、无敌与得分。倒计时不投球。重开新建 Session 和 Phaser 场景，清理旧输入、实体及监听。
- 每个命中保存实际 `ownerCharacterId`、`projectileId` 和时间，供 M4 的“玩家惊讶／发射者开心”双气泡接入。
- 结算一次性保存最长生存与最高分；浏览器拒绝存储或旧数据损坏时仍能继续游戏。
