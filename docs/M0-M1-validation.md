# M0 / M1 验收记录

日期：2026-10-16，样图还原修订。范围：选人入口与固定操场自由移动，手机横屏优先。

## 已验证

- `npm run build`：TypeScript 与 Vite 生产构建通过。
- `npm test`：22 项逻辑测试通过，覆盖抽签、速度、斜向归一化、模拟摇杆、边界、长帧限制、倒计时、暂停/重开，以及三种屏幕尺寸的场地投影和 Retina 一致性。
- `npm run test:e2e`：9 项通过，1 项跳过（桌面不重复手机旋转测试）。覆盖六卡选中记忆、键盘到边界、暂停冻结、重开、返回选人、多指触控、取消、旋转屏幕。
- 调整画布方案时发现原 Phaser RESIZE 在快速横竖屏切换后会短暂保持旧显示尺寸；改为 ResizeObserver 驱动的渲染缓冲区与 100% CSS 尺寸后，整套测试通过。
- 生产构建 `/CatBall/`：1440×900、844×390、568×320 三种尺寸均无脚本错误、资源 404 或水平溢出；生产包没有开发测试接口。
- 手机 844×390 下画布 CSS 为 844×344，DPR 2 的实际缓冲区为 1688×688。背景与人物均等比缩放，不再给画布两侧预留 100+ px 控制栏。
- 生产包阻断全部角色与美术文件后，仍可选择欢欢、进入代码占位操场并完成倒计时。
- 检查新图集透明通道、独立角色边界和实际截图。桌面、手机、小屏手机截图位于 `docs/previews/v2/`。
- 生产目录约 5.98 MB（未压缩总文件大小），Phaser 分块 gzip 约 323 KB。原始 PNG、美术样稿、提示词均不随游戏发布。

## 本轮边界

- 空操场、透明立绘、像素角色与标题为内置 imagegen 依据样稿生成的派生素材，细节不保证逐像素一致；选人卡片与 HUD 头像仍引用用户原图。
- 六名角色均有四帧腿部行走动画，以实际位移驱动，支持左右镜像。正式背面和 Kick / Roll 动画后续制作。
- 四名场外伙伴不移动或发球；正式战斗、受伤、技能、道具和事件表情按后续里程碑加入。
- 当前计时是练习时间，不写正式成绩。三颗心和 0 分用于 HUD 布局。
- 浏览器检查使用本机 Chrome 与移动设备模拟，未进行 iOS Safari / Android 真机触感测试。
- 已有 GitHub Pages 手动发布工作流；未推送或发布。

## 移动动画修订验收

- 坚果 idle / walk 均为白色脸部和身体、灰色外耳及整条尾巴、蓝眼；欢欢 idle / walk 均为短尾。保留用户的原始头像设定图。
- 单元测试新增：四帧步态与帧率无关、模拟摇杆步频、零位移回站立、暂停保持姿势、一次性 Kick/Roll 动作时序接口。所有 22 项通过。
- 浏览器新增：手机和桌面逐一选择六角色，检查实际 player-walk 贴图的四个帧均被绘制；松手回 characters-idle；暂停冻结腿部帧。共 9 项通过、1 项桌面旋转测试跳过。
- 生产 `/CatBall/` 实录坚果、欢欢移动，无脚本错误或 404；生产版无开发观察接口。站立/移动截图和 WebM 录像在 `docs/previews/movement/`。
- 阻断全部美术资源后，仍可进入欢欢场景并移动，未出现脚本错误；代码回退角色也修正了灰耳灰尾与短尾。
- 每局只加载玩家对应的额外行走图集（约 185–217 KiB）；发布目录总大小 5,984,501 字节。原 PNG 与录屏不进入发布目录。
- 动作时序接口已经验证，Kick / Roll 的贴图、战斗判定和技能按钮仍按 M3 接入。
