# CatBall V1.1 规则增补

2026-10-17，依据本轮用户要求。在 `GAME_SPEC_V1.0.md` 基础上覆盖以下条目，其他玩法、美术、Kick 范围及命中规则保持原样。

## 玩法介绍

选人页面与暂停菜单提供「玩法介绍」。说明移动躲避三种球、鸭子 / 野猪追踪与冲刺、近距离 Kick、Roll、道具、计分和手机 / 键盘操作。强调球不能踢、空踢也消耗冷却。介绍使用可滚动弹窗，手机横屏可关闭并返回；暂停中阅读不推进对局。

## 音频

- 使用用户提供的 `Music/60-Seconds_-_2020-04-24_-_Arcade_Kid_-_FesliyanStudios.com_-_David_Renda.mp3`。网页使用其中前 60 秒的压缩 AAC，循环播放，保留音乐作者署名。
- 初次点击「开始游戏」后播放，尊重浏览器的用户手势要求；暂停 / 后台 / 返回选人 / Game Over 停播，继续对局从原处播放，重新开始从头播放。
- 每次成功踢飞鸭子或野猪触发一次短合成猫叫。沿用现有 Kick 命中规则，追踪 / 蓄力 / 冲刺阶段的成功命中均触发；空踢不触发，帧更新不重复触发。
- 选人页和暂停菜单提供统一声音开关，记住选择。静音期间发生的 Kick 不会在重新开声时补播；媒体不可用或本地存储受限不阻止对局。

## 血量

- `initialHealth = 3`，`maxHealth = 5`，每次新局仍为 3 HP。
- 南瓜恢复 1 HP，最多 5 HP。3 HP 时可以补到 4，再补到 5。
- 5 HP 拾取南瓜会消耗道具但不增加血量，提示「生命已满」。
- HUD 固定五个心位，未拥有 / 已损失的心显示暗色。伤害仍为每次有效碰撞 -1 HP；免疫、归因和 0 HP Game Over 不变。
