# 角色素材接入说明（V1.0）

此项目可以**没有任何正式 PNG** 先运行。生成的角色大图是“概念设定图”，不是已经按动作切分、具有透明背景的游戏精灵。

## 角色 ID

- silver_cat — 坚果（29中；仅耳朵和尾巴灰色，其余毛色白色；蓝眼；黑色肉垫）
- white_cat — 白猫（29中；浅绿眼；粉色肉垫）
- tabby_cat — 灰虎斑猫（金陵中学）
- point_cat — 重点色猫（树人中学）
- poodle — 欢欢，灰泰迪（29中；短尾）
- ragdoll_cat — 长毛布偶猫（一中实验）

## 推荐文件名

```text
public/assets/characters/<character_id>/
  idle.png
  focused.png
  happy.png
  confident.png
  surprised.png
  run_01.png
  run_02.png
  roll_01.png
  roll_02.png
  kick_01.png
  kick_02.png
```

`idle.png` 建议为角色独立完整立绘（透明背景），四种表情最好是**单独导出的正面头像**。所有资源缺失时必须启用程序内占位，不得崩溃。

头像资源按事件显示，不代表所有角色都常驻气泡。

- **Roll 翻滚全程不显示任何表情气泡**：玩家与四名投球者的放大头像、气泡和表情文字占位全部隐藏。用翻滚姿态、残影及贴近角色的无敌效果表达动作；角色本体与 HUD 正常显示。已有状态继续计时，结束后不重播过期气泡。
- **Kick 成功时，同时展示 5 个气泡**：场内玩家使用自己的自信头像，四名场外投球者（猫或狗）各使用自己的惊讶头像。中央玩家也必须显示独立头像气泡。优先从各角色原设定图右上表情四宫格导出：左上为自信，右下为惊讶。
- **玩家被球命中时，仅玩家和命中球的发射者展示表情头像气泡**，分别为惊讶与开心（受规格书中的表情优先级约束）；其余三名场外角色不展示头像气泡，也不展示表情文字占位。

开场展示保持原设定；各事件的气泡范围、时序及表情优先级详见 `GAME_SPEC_V1.0.md` §12。

野猪/鸭子在 `public/assets/animals/`；球在 `public/assets/projectiles/`；南瓜猫条在 `public/assets/items/`；操场在 `public/assets/background/`。

## 后续美术替换前要核对

1. 所有角色素材尺寸、锚点、透视角度统一。
2. 胸口校名文字准确，尤其“金陵中学”“树人中学”“一中实验”。
3. 表情贴图与角色 ID 一一对应；角色在球场内显示小头像时要保持辨识度。
4. 图片显示尺寸不等于碰撞体尺寸：使用游戏配置中的独立圆形碰撞半径。
5. 素材加入后，仍须通过碰撞、翻滚、Kick 和时间管理测试。
6. 被球命中的反馈只出现玩家与准确发射者的两个头像气泡，其他三名角色的头像资源不得自动常驻显示。
7. Kick 成功的反馈必须同时出现中央玩家的自信气泡和四名场外投球者各自的惊讶气泡，头像身份准确且不遮挡主要动作；空踢不出现这组气泡。
8. Roll 全程不得出现任何角色的表情气泡或放大头像；检查残影与无敌效果能表达翻滚，同时不遮挡球和追踪动物。

## M0 / M1 实际素材接入（2026-10-16，样图还原版）

- 六名角色 `Image/*.png` 原样保留；整版原图以全分辨率 WebP 发布。卡片和 HUD 继续通过 SVG 窗口展示原图的自信头像。
- 用户反馈第一版画面过于压缩后，改用 `Art/generated/` 的独立背景、透明立绘和像素角色素材。它们由内置 imagegen 参考确认样稿整理，并非逐像素原图抠出；完整提示词及来源在 `Art/asset-provenance.json`。
- 操场分为桌面和宽屏版，均移除了样稿中角色、球、鸭子、选择圈与 UI。场内人物实时独立绘制，卡片、HUD、按钮由代码实现。
- 选人页保持左侧大立绘、右侧三列两行卡片、下方橙色开始按钮。手机界面不再将卡片改成压缩的左右文字行。
- 游戏画布占满 HUD 下方空间，左右控制器覆盖草地边缘；背景、人物均等比缩放。逻辑世界仍为固定配置，透视投影只改变显示。
- PNG 原稿与 WebP 发布副本均保留真实透明通道。代码不对素材抠图、重绘或改变宽高比例。
- 场内现用 idle 图集与各角色四帧行走图集；按实际移动距离播放腿部动作，停止回站立，暂停冻结当前帧。左右方向镜像；正式背面、Kick 和 Roll 贴图后续补齐。`characterSprites.ts`、`arena.ts` 保留为加载失败时的回退。
- 图片缺失不影响选人及进入游戏。当前未新增事件表情规则，Kick / 受击 / Roll 气泡系统继续按后续里程碑实现。
