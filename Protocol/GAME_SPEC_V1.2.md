# CatBall V1.2 角色专属技能

2026-10-17，依据用户提出的六项专属技能。版本号 1.2.0。本文件覆盖 V1.0 中「角色能力相同」的设定，并按角色扩展 V1.1 的生命上限；其他规则沿用。

## 六个被动

| 角色 | 效果 | 实际数值 |
| --- | --- | --- |
| 元宵 | 道具刷新等待减少 3 秒 | 17–27 秒，原为 20–30 秒 |
| 欢欢 | 翻滚冷却减少 3 秒 | 7 秒，原为 10 秒 |
| 坚果 | 猫条无敌延长 3 秒 | 8 秒，原为 5 秒 |
| 阿福 | 普通移动速度乘以 1.1 | 211.2 世界单位/秒，原为 192 |
| 球球 | 成功 Kick 后的震惊延长 1 秒 | 4 秒，原为 3 秒 |
| 赛赛 | 生命上限增加 1 点 | 6 HP，原为 5 HP；初始仍为 3 HP |

技能无需额外按键，仅所选玩家角色的技能生效。四周投球者不触发各自的被动，也不为玩家提供额外加成。所有角色每次开局均为 3 HP；重开、返回选人、换角色会重新建立本局属性，不累加上局加成。

## 边界规则

- 元宵：首次刷新、拾取后的下一次刷新、道具过期后的下一次刷新均使用 17–27 秒。道具保留时间仍为 10 秒，鸭子 / 野猪的刷新不受影响；没有安全出生点时仍短暂重试。
- 欢欢：冷却从开始翻滚时起算。距离仍为 144 世界单位、持续 0.45 秒，全程无敌，所有气泡隐藏。
- 坚果：重复吃猫条将该项无敌计时重置为 8 秒，不累加。翻滚、受伤保护和猫条仍独立计时。
- 阿福：加速只影响普通移动，摇杆小幅慢走按比例加速；斜向归一化、场地边界不变。翻滚距离与持续时间不受影响。
- 球球：仅成功踢飞动物生效。保留 0.5 秒定格，之后给予四名投球者完整 4 秒震惊；移动、投球调度和蓄力速度减半，已飞出的球保持原速。原有气泡显示时长与 Roll 隐藏规则不变。
- 赛赛：南瓜可将血量从 3 → 4 → 5 → 6，满 6 HP 时不再增加。每次有效伤害仍扣 1 HP，0 HP 结束。

## 界面与发布

- 选人页面显示当前角色的专属被动。
- 玩法介绍每次打开时读取当前角色，显示已包含加成的规则与六人技能列表；暂停阅读不推进对局。
- HUD 根据角色显示五个 / 六个心位；猫条、翻滚和震惊倒计时反映实际持续时间。满血提示显示实际生命上限。
- 不新增美术、音频或外部依赖。沿用 GitHub Pages 子路径和 Cloudflare Pages 根路径部署。
